## Zbiór danych
Ze względu na ograniczenia rozmiaru plików na GitHub (zbiór danych ma ok. 144 MB), plik `creditcard.csv` nie został dołączony do repozytorium.

Zbiór danych można pobrać bezpośrednio z platformy Kaggle:
👉 [Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

### Instrukcja uruchomienia:
1. Pobierz plik `creditcard.csv` z powyższego linku.
2. Umieść plik w tym folderze (`PROJEKTY/Fraud_detection/`).
3. Uruchom skrypt `Fraud_detection.py`.
